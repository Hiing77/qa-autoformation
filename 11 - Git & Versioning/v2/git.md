# 🌿 Gestion de Version & Bonnes Pratiques Git

Ce module met en avant ma maîtrise des outils de versioning et des bonnes pratiques de collaboration indispensables en assurance qualité (QA) et en développement.

## 🎯 Objectifs & Compétences Validées
* **Traçabilité du code :** Capacité à versionner proprement un projet, à suivre l'historique des modifications et à structurer les commits.
* **Propreté et hygiène du dépôt :** Gestion rigoureuse des fichiers ignorés (`.gitignore`), suppression des fichiers de cache (`__pycache__`) et prévention des erreurs de configuration (dossiers `.git` imbriqués ou "parasites").
* **Collaboration & Branches :** Utilisation des flux de travail Git (création de branches, validation et fusion).

---

## 📝 Conventions de Commits Utilisées
Pour assurer une lecture claire de l'historique par l'équipe ou les développeurs, j'applique la convention des messages standardisés :
* `feat:` Ajout d'une nouvelle fonctionnalité, d'un script ou d'un exercice.
* `fix:` Correction d'un bug dans le code ou d'un problème de configuration (ex: nettoyage du cache Git).
* `chore:` Tâches de maintenance, de rangement ou de mise à jour de la documentation (`README.md`, `.gitignore`).

---

## 🛠️ Commandes Clés Maîtrisées
* `git status` / `git add` / `git commit` : Suivi et validation des modifications locales.
* `git rm --cached` : Retrait de fichiers ou dossiers du suivi Git tout en les conservant en local.
* `git push` : Synchronisation avec le dépôt distant GitHub.
