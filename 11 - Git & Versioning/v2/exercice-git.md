## 🛠️ Focus Technique : Maîtrise de Git & GitHub
Dans le cadre de la semaine 11, j'ai mis en place un workflow professionnel simulant un environnement de travail réel :
1. **Isolation des tâches :** Création d'une branche dédiée (`ajout-tests-login`) pour développer une modification sans impacter la branche principale.
2. **Traçabilité :** Validation des modifications via des messages de commit normalisés et clairs.
3. **Collaboration & Revue :** Ouverture d'une *Pull Request* (PR) sur GitHub, vérification de l'absence de conflits, puis fusion (*merge*) validée sur la branche `main`.
4. **Nettoyage :** Suppression de la branche éphémère après intégration pour garder un dépôt propre et professionnel.
