Description

🐛 DESCRIPTION DU BUG
La page bug, lors de la connexion avec les bon identifiants

👣 ÉTAPES DE REPRODUCTION
Cliquer sur le bouton "Se connecter" ou "S'inscrire / Se connecter" en haut à droite.

Saisir l'adresse email valide du compte de test dans le champ "Nom d'utilisateur ou e-mail".

Saisir le mot de passe correct dans le champ "Mot de passe".

Cliquer sur le bouton "Se connecter" pour valider le formulaire.

❌ COMPORTEMENT ACTUEL (Le Bug)
La page se fige, puis une page blanche ou une erreur de serveur s'affiche. Impossible de se connecter.

🎯 COMPORTEMENT ATTENDU
L'utilisateur est connecté avec succès (sa photo de profil ou ses initiales apparaissent en haut à droite).

L'utilisateur est redirigé vers son fil d'actualité personnel Vinted.

Aucun message d'erreur ne s'affiche.

💻 ENVIRONNEMENT DE TEST
OS : Windows 11 

Navigateur : Chrome (Dernière version)
