📋 INFORMATIONS GÉNÉRALES
ID du Cas de Test : CT-CONN-005

Objectif : Vérifier l'impossibilité de se connecter en laissant les champs vides.

⚙️ PRÉREQUIS
L'utilisateur n'est pas connecté.

L'utilisateur se trouve sur la page d'accueil de Vinted.

👣 ÉTAPES DE REPRODUCTION
Cliquer sur le bouton "Se connecter" ou "S'inscrire / Se connecter" en haut à droite.

Cliquer directement sur le bouton "Se connecter" sans rien saisir dans les champs.

🎯 RÉSULTAT ATTENDU
L'utilisateur n'est pas connecté.

Des messages d'erreur de validation s'affichent sous les champs concernés (ex : "Veuillez remplir ce champ").

Les champs "Nom d'utilisateur ou e-mail" et "Mot de passe" sont surlignés en rouge pour indiquer l'erreur.
